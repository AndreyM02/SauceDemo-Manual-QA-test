# BUG-001: Added product is not displayed in cart after Add to Cart

**Severity:** Major  
**Priority:** High  
**Environment:** Chrome on Windows

## Preconditions
User is on a product page.

## Steps to Reproduce
1. Open a product page.
2. Select product options if required.
3. Click **Add to Cart**.
4. Open **My Cart**.
5. Open the browser console.

## Expected Result
The selected product is displayed in the cart with its details.

## Actual Result
The cart count updates to 1, but the selected product is not displayed in the cart.

The browser console shows:

`TypeError: Cannot read properties of null (reading 'description')`
